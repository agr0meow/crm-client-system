# CRM «Клиентский путь»

Информационная система автоматизации взаимодействий с клиентами — от первого касания до заключения договора.

Учебный проект по дисциплине «Проектная деятельность в ИТ».
Автор: Ермаков Никита Александрович, группа о.ИЗДтс 23.1/Б3-26.

## Назначение

Система ведёт каждого потенциального клиента по воронке продаж:

1. Первое касание (заявка с сайта, звонок, письмо, мессенджер).
2. Квалификация лида.
3. Выявление потребностей.
4. Коммерческое предложение.
5. Переговоры.
6. Заключение договора.

На каждом этапе фиксируются контакты, задачи менеджера, история коммуникаций и документы.
