# Внедрение и сопровождение

1. Сборка образа: `docker build -t crm-client-system .`
2. Запуск: `docker run -d --name crm -p 8080:8080 crm-client-system`
3. Обучение менеджеров отдела продаж работе с карточкой клиента и воронкой.
4. Сопровождение: исправления — через ветки `hotfix/*` от `main`, доработки — через `develop`.
