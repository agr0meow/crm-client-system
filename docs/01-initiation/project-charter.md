# Устав проекта CRM «Клиентский путь»

## Цель
Сократить потери обращений клиентов и время от первого касания до подписания договора за счёт единой системы учёта взаимодействий.

## Задачи
- собрать все обращения клиентов в одном месте;
- вести клиента по этапам воронки продаж;
- напоминать менеджеру о следующих шагах;
- формировать коммерческие предложения и договоры по шаблонам;
- показывать руководителю отчёты по воронке.

## Сроки
| Этап | Длительность |
|---|---|
| Инициация | 1 неделя |
| Анализ требований | 2 недели |
| Проектирование | 2 недели |
| Разработка | 6 недель |
| Тестирование | 2 недели |
| Внедрение | 1 неделя |

## Команда
| Роль | Зона ответственности |
|---|---|
| Руководитель проекта | планирование, контроль сроков, приёмка |
| Бизнес-аналитик | требования, техническое задание |
| Архитектор | архитектура, модель данных |
| Разработчики | реализация модулей |
| Тестировщик | планы тестирования, тесты |
| DevOps-инженер | развёртывание, сопровождение |
