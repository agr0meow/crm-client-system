# Архитектура CRM «Клиентский путь»

Трёхуровневая архитектура:

1. **Клиент** — веб-интерфейс (SPA) для менеджеров и руководителя.
2. **Сервер приложений** — REST API на Go: модули «Клиенты», «Воронка», «Задачи», «Документы», «Отчёты».
3. **Хранилище** — PostgreSQL; файлы КП и договоров — в объектном хранилище.

Интеграции: форма заявки на сайте, почтовый ящик отдела продаж, телефония (журнал звонков).
