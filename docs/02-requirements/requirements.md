# Требования к CRM «Клиентский путь»

## Функциональные требования
- ФТ-1. Регистрация обращения из любого канала: сайт, телефон, e-mail, мессенджер.
- ФТ-2. Карточка клиента: контакты, компания, ответственный менеджер, история касаний.
- ФТ-3. Воронка продаж из этапов: первое касание → квалификация → потребности → КП → переговоры → договор.
- ФТ-4. Перевод клиента между этапами только по разрешённым переходам; на любом этапе сделку можно закрыть как проигранную с указанием причины.
- ФТ-5. Задачи и напоминания менеджеру (звонок, встреча, отправка КП).
- ФТ-6. Генерация коммерческого предложения и договора по шаблону.
- ФТ-7. Отчёты: конверсия по этапам, средний срок сделки, причины отказов.

## Нефункциональные требования
- НФТ-1. Веб-интерфейс, работа в современных браузерах.
- НФТ-2. Разграничение прав: менеджер, руководитель отдела продаж, администратор.
- НФТ-3. Время отклика интерфейса — не более 2 секунд.
- НФТ-4. Хранение персональных данных в соответствии с 152-ФЗ.
- НФТ-5. Резервное копирование базы данных ежедневно.
